# Analisis Aplikasi Pertemuan 1

## Aplikasi yang Diamati
Aplikasi yang dikembangkan pada pertemuan 1 adalah aplikasi profil mahasiswa sederhana berbasis Flutter.

## Pengguna
Aplikasi ditujukan untuk mahasiswa atau pengguna yang ingin melihat informasi profil dan data mahasiswa secara sederhana.

## Tiga Fitur Utama
1. Menampilkan informasi profil mahasiswa.
2. Menampilkan data mahasiswa yang disimpan dalam format JSON.
3. Menampilkan foto atau gambar profil mahasiswa.

## Usulan Perbaikan
Aplikasi dapat dikembangkan dengan menambahkan navigasi antarhalaman, tampilan yang lebih interaktif, serta fitur untuk memperbarui informasi profil.
